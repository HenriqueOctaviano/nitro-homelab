## Git CLI - PATH Fix

After the GitHub Desktop Git executable was confirmed, the user PATH was updated so future terminals can run `git` directly.

Command:

```powershell
$GitPath = "$env:LOCALAPPDATA\GitHubDesktop\app-3.6.4\resources\app\git\cmd"
$UserPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($UserPath -notlike "*$GitPath*") {
    [Environment]::SetEnvironmentVariable("Path", "$UserPath;$GitPath", "User")
}
```

Observation:

The current terminal session did not immediately see the updated PATH. The session PATH was refreshed manually.

Command:

```powershell
$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")
```

Verification:

```powershell
git --version
git status
```

Learning note:

PowerShell treats a quoted executable path as text unless it is called with `&`.

Example:

```powershell
& "$env:LOCALAPPDATA\GitHubDesktop\app-3.6.4\resources\app\git\cmd\git.exe" --version
```

Useful PATH inspection command:

```powershell
$env:Path -split ";" | Select-String "GitHubDesktop"
```

Meaning:

- `$env:Path` reads the current session PATH.
- `-split ";"` separates the PATH into one folder per line.
- `|` sends those lines to the next command.
- `Select-String "GitHubDesktop"` filters only matching lines.
