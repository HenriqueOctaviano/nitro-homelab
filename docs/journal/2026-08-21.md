# 2026-08-21 Lab Journal

## Session Goal

Start documenting the Nitro homelab project in GitHub and make the repository the source of truth for the learning process.

## Initial Context

The target machine is an Acer Nitro 5 with:

- 16 GB RAM
- Two NVMe SSDs totaling approximately 1.5 TB
- Windows host

The intended lab scope includes:

- Kali Linux
- Linux and Windows servers
- APIs for other machines
- AI/JARVIS-style assistant experiments
- Infrastructure, networking, cybersecurity, DevOps and development practice

## Documentation Rule

Everything useful for reproducing the lab should be documented in GitHub:

- Commands
- Results
- Errors
- Fixes
- Decisions
- Architecture notes
- Learning notes

Sensitive information must not be committed.

## Information To Exclude

Do not commit:

- Passwords
- Tokens
- API keys
- SSH private keys
- Personal email addresses
- Product keys
- Unneeded serial numbers
- Home SSIDs
- Public IP addresses
- Personal file contents
- Private paths that reveal unnecessary personal information

## GitHub Access Decision
